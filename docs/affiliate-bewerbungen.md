## Technische Aktivierung nach Annahme

1. Im ADCELL-Konto den Advertiser-Status auf angenommen prüfen.
2. Für jedes konkrete Produkt im Deeplink-Generator einen Trackinglink erstellen.
3. Saubere Händler-Ziel-URL und Tracking-URL getrennt im Produktangebot speichern.
4. Programm-ID, erlaubten Tracking-Host und Affiliate-Status im Händlerregister aktivieren.
5. Kennzeichnung, Weiterleitung, Preis, Variante und mobile Darstellung stichprobenartig prüfen.
6. Datenschutz- und Affiliate-Hinweise aktualisieren und den statischen Build erneut abnehmen.

Es ist keine GitHub Action und keine Laufzeitdatenbank erforderlich. Die Zuordnung kann als versionierte JSON-Datei erfolgen und wird beim statischen Cloudflare-Build eingebaut.
